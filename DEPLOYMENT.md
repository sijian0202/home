# Question Box Portfolio

Published portfolio for Wang Xiaotong, including seven presentation pages and the
interactive Question Box Demo. This is a browser-local mock demonstration, not a
live multi-user backend. Refreshing restores the initial demo state.

## GitHub Pages

- Repository: `sijian0202/home`
- Branch: `main`
- Publishing directory: `/ (root)`
- Expected public URL: `https://sijian0202.github.io/home/`
- Entry: `index.html`
- Interactive Demo: `demo.html`

Keep `assets/` and `portfolio/` next to the HTML files. All runtime files use
relative paths so project-site hosting under `/home/` works without rewriting.
No package installation or build step is needed for this static publication.

The original working project and its frozen prototype remain separate; this
repository is a publication copy, not an installation environment.
